## 빠른 결정사항

- 스택: React + TypeScript + Vite / FastAPI + Pydantic / SQLite
- 데이터: 공연 20건 이상, 공연장 4곳 이상; 실제/데모 출처 구분
- 추천: 날짜·지역·가격 하드 필터 → 분위기/혼자 관람 가중치 → 최대 3개
- 등록: 이미지 → AI 추출 → **사용자 검수** → DB 등록
- 가이드: 공연과 공연장을 분리, 검증된 한/영 텍스트 사용
- 시연: 로컬 우선. 공개 배포라면 영구 DB/이미지 저장·등록 인증을 추가

## 구현 전 팀 합의가 필요한 것

- AI 제공자/모델 및 비용 한도
- 행사 실제 개발 시간·인원 구성
- 이미지 출처와 시드 데이터 20건 검수 담당
- 로컬 데모만 할지 공개 URL도 만들지

> 이 패키지는 **기획 및 구현 계약**이지 완성된 코드가 아니다. 기술 세부는 각 문서의 예제·검증 규칙을 기준으로 구현한다.
